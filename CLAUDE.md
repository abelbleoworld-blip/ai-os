## Архитектура 2ⁿ — фрактальный принцип

Пользователь принял универсальный принцип (2026-04-17): стабильные конфигурации = `2ⁿ`. Применяется ко всем проектам.

| 2ⁿ | Что |
|---|---|
| 16 | модуль / набор фич |
| 64 | система / якорь-документ ровно 64 строки |
| 256 | целевой размер Python-файла |
| 1024 | корпус-статья |

**Для AI-OS:** целевое число модулей = **16 (2⁴)**, не 19, не 15.
- Сейчас 19 (избыток) → консолидировать в 16 при разморозке
- DESIGN_SPEC указывает 15 → добавить один или объединить логику

Якорь-документ (типа DESIGN_SPEC, ARCHITECTURE.md) — целиться в 64 строки, 4 секции по 16:
1. (1–16) Тезис — что и зачем
2. (17–32) Метод / структура
3. (33–48) Литература / ограничения
4. (49–64) TODO / cross-links

## Стиль общения с пользователем

- **Русский** — основной язык. Английский — перевод.
- Максимально ёмко, без воды и преамбул.
- Каждый нетривиальный шаг — одна строка «зачем» (1 предложение, не 3).
- Альтернативы — только когда выбор неочевиден. Формат: `X [выбрано] — потому что Y. Альтернатива: Z — хуже из-за W.`
- Таблицы для сравнений — пользователь хорошо их читает.
- TaskCreate / TaskUpdate — обязательно для работ от 3 шагов, обновлять в реальном времени.
- Маркеры: ◼ done / ◻ pending / ⏳ blocked.
- НЕ объяснять очевидное (`ls`, `git status`).
- НЕ писать «готово!» + пересказ команд.
- Новые термины (от пользователя или от меня) — отмечать вслух, уточнять. Обучение двустороннее.

## Mesh-Memory — координация между сессиями

Папка `~/Documents/Projects/mesh-memory/` — git-synced между Mac/iMac/Beelink сессиями Claude Code.

- Bare repo: `root@10.10.0.12:/opt/git/mesh-memory.git` (Abel HQ, через WG mesh)
- На M1 автопул каждые 60 сек: LaunchAgent `com.user.mesh-memory-sync`
- На iMac пока без автопула — настроить отдельно если нужна синхронизация
- Push — вручную после commit

**Когда писать в mesh-memory:**
- Архитектурные решения, влияющие на >1 узел
- Изменения протоколов, портов, hostname'ов
- Знания, которые могут пригодиться другой сессии Claude Code

**Когда НЕ писать:**
- Личные заметки внутри проекта (это в локальный `docs/`)
- Секреты, токены, ключи
